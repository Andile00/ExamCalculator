Exam Eligibility Calculator

A simple C# app that checks if a student qualifies for an exam based on their weighted average.

Minimum required: 50%


 Quick Start (2 Minutes)

Prerequisites
Docker** installed → [Download here](https://www.docker.com/products/docker-desktop)

Run the App

Open your terminal and run:

docker pull andile01/exam-calculator:latest


docker run -it andile01/exam-calculator:latest
